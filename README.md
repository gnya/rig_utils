## rig_utils

### 機能
* ArmatureとEmptyに設定されたアセット関係のカスタムプロパティを操作できるようにするUI
* レストポーズから移動させたボーンだけを表示（Shiftで非表示のレイヤー含めて表示）
* アニメーションを設定したボーンだけ表示（Shiftで非表示のレイヤー含めて表示）
* 設定したアセットフォルダからアセットを読み込む機能
  * アドオン設定からアセットフォルダを設定できます
* 読み込まれたアセットにより新しいアセットがあれば更新する機能
* ボーンのトランスフォームをワールド座標系でコピーペーストする機能
  * `Shift`+`Alt`+`C` でコピー `Shift`+`Alt`+`V` で貼り付け
