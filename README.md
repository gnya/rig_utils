## rig_utils

### 機能
* ArmatureとEmptyに設定されたアセット関係のカスタムプロパティを操作できるようにするUI
* レストポーズから移動させたボーンだけを表示（`Shift`で非表示のレイヤー含めて表示）
* アニメーションを設定したボーンだけ表示（`Shift`で非表示のレイヤー含めて表示）
* オーバーライドされたボーンだけを表示（`Shift`で非表示のレイヤー含めて表示）
* 設定したアセットフォルダからアセットを読み込む機能
  * アドオン設定からアセットフォルダを設定できます
* 読み込まれたアセットより新しいアセットがあれば更新する機能
* ボーンのトランスフォームをワールド座標系でコピーペーストする機能
  * `Shift`+`Alt`+`C` でコピー `Shift`+`Alt`+`V` で貼り付け
  * ワールド座標系以外にもローカル座標系、親付きローカル座標系、ポーズ座標系を選択できます
* プレビューを1ボタンで書き出す機能（動画で書き出した際ファイル名にフレーム番号を含まない）
* 選択ボーンと同じトランスフォームを持ったエンプティを追加する機能
* アニメーションのすべてのグラフにステップ補間を追加する機能
* 古いリグから新しいリグへトランスフォームを転送する機能（CTR接頭辞のあるリグが対象）
